## Navicat for SQL Server 核心功能拆解

买之前知道这个工具能干什么，比什么都重要。

**数据库连接与管理**

左侧连接面板，把所有 SQL Server 实例都列在一起。本地、局域网内的服务器、云端实例，切换起来就是点一下的事。新建数据库、管理表结构、操作存储过程和触发器，全有对应的图形界面，不需要记命令。

**SQL 编辑器**

功能上没有太大惊喜，但写代码体验好是真的。自动补全、代码片段插入、语法高亮，写复杂查询时效率比纯命令行高一大截。企业版还有可视化执行计划，可以直接看到查询和数据库交互的详细情况。

**数据迁移与同步**

这是 Navicat 的强项之一。数据传输、数据同步、结构同步三套工具，跨数据库系统迁移数据都有详细的步骤引导。两个数据库之间的结构差异，对比之后生成脚本，几秒内完成。

**备份与自动化**

通过 SQL Server Backup GUI，可以设置定期备份任务，也可以把常用的查询、导入导出操作做成批处理作业，定时运行，运行完了发邮件通知。

**安全连接**

SSH 隧道和 SSL/TLS 加密连接，在公网环境访问数据库时不用担心数据传输安全问题。
